# Photos People or Not

### Pengantar
Model ini dilatih pada dataset dengan kondisi ideal: manusia selalu full-body dan jelas, serta non-human tanpa adanya manusia.
Akurasi 100% pada validasi menunjukkan model bekerja sangat baik untuk data tersebut.
Namun, model belum diuji pada kasus dunia nyata seperti CCTV, orang kecil, atau kerumunan.
Untuk penggunaan praktis, disarankan melakukan uji coba ekstensif dengan data real-world.
